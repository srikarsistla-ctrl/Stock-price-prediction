How to read this

Daily equity direction is close to unpredictable. This project is built to measure that rather than hide it: stationary features only, a chronological train/validation/test split, a baseline that is genuinely hard to beat, costs charged on every trade, and every live prediction logged before it is shown. It is a modelling and evaluation exercise, not investment advice.
